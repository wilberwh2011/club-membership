# Constitution Inputs (decisions to feed into /speckit-constitution)

These are inputs, not the constitution itself.

## Confirmed by project owner

- **Bilingual UI:** The user interface must support both English and Chinese (Simplified). Users can switch language; all labels, messages, and reports are available in both. Terms follow docs/brief/glossary.md.
- **Privacy first:** Member personal data (names, contact details, birthdays, payments) is never committed to the repo, never written to logs, and never pasted into AI prompts. Development and testing use synthetic data only.
- **No card processing:** The system records payments; it does not process card payments.
